# 局域网访问、域名与开机自启

适用：单店、纯本地、无云端；收银主机 = Windows 电脑；手机/自助机用浏览器访问。

---

## 一、结论先说

| 你想要的 | H3C 家用路由能否直接做 | 可行做法 |
|---|---|---|
| 给主机固定 IP | **能**，有「DHCP 静态列表」 | 见第二节 |
| 局域网自定义域名（如 pos.home.arpa） | **不能**，H3C Magic 系列 Web 后台没有本地 DNS 记录/域名重写功能 | 主机上跑一个本地 DNS（AdGuard Home），见第三节 |
| 手机用摄像头扫码 | 已内置，但**必须走 https** | 8443 自签证书，见第四节 |
| 手机扫码直接进收银台 | 已内置，不依赖域名 | 后台「设置」或首页的二维码，见第五节 |
| 开机自动启动、崩溃自启 | 已提供脚本 | 见第六节 |

> H3C 企业级（ER / MSR 系列，命令行）支持 `ip host` 静态域名解析；家用 Magic 系列（默认管理地址 `192.168.124.1`）只开放 DHCP 静态绑定，没有 DNS 服务器功能。这一条是查过官方手册确认的。

---

## 二、在 H3C 上把收银主机固定成同一个 IP

路由器要固定给主机分配同一个 IP，否则域名/二维码收藏都会失效。

1. 浏览器打开 `http://192.168.124.1`，登录管理后台（首次配置时设的管理密码）。
2. 进入 **更多 → 接口管理 → DHCP 列表 → DHCP 客户端列表**。
3. 在列表里找到收银主机（看它的 MAC 地址，主机上 `ipconfig /all` 可查），点 **添加**，系统会把当前的 IP/MAC 自动填进静态地址分配列表。
4. 再到 **DHCP 列表 → DHCP 静态列表** 确认条目已存在；若手工新增，填 MAC + 想要的 IP（如 `192.168.124.50`），点 **确认**。
5. 主机上 `ipconfig /release` 再 `ipconfig /renew`，确认拿到的是这个固定 IP。

> 注意：静态绑定里的 IP 不能落在 WAN 口网段里，也不能和路由器自身地址重复。

## 三、局域网自定义域名（主机跑本地 DNS）

### 3.1 装 AdGuard Home（Windows 版）

1. 官网下载 Windows 版，解压后运行 `AdGuardHome.exe`。
2. 首次打开 `http://127.0.0.1:3000` 走安装向导，管理端口默认 3000，DNS 端口保持 **53**。
3. 装完把它的 DNS 服务设为开机自启（AdGuard Home 自带“作为服务安装”选项，或用第五节的计划任务）。

### 3.2 加域名重写

AdGuard Home → **过滤器 → DNS 重写** → 添加：

| 域名 | 解析目标 |
|---|---|
| `pos.home.arpa` | 收银主机的固定 IP，例如 `192.168.124.50` |

`home.arpa` 是 RFC 8375 专门给家庭网络保留的域名后缀，不会和公网域名冲突。也可以用 `pos.shop.lan` 这类自定义后缀，只要带点就行。

再在 **设置 → DNS 设置** 里把上游 DNS 填成运营商/公共 DNS（如 `223.5.5.5`），否则手机其他网站的解析会失败。

### 3.3 安卓手机改 DNS

1. 设置 → WLAN → 长按当前 Wi‑Fi → 修改网络 → 高级选项。
2. IP 设置保持 **DHCP**，DNS1 填 **收银主机 IP**，DNS2 填 **路由器 IP**（`192.168.124.1`，主机没开机时手机还能上网）。
3. 设置 → 网络和互联网 → **私人 DNS（Private DNS）必须设为「关闭 / 自动」**，否则安卓会绕过本地 DNS，域名解析不到。
4. 手机浏览器打开 `https://pos.home.arpa:8443/pos` 验证（要摄像头扫码必须用 https，见第四节）。

### 3.4 想去掉端口号

| 目标 | 做法 | 说明 |
|---|---|---|
| 去掉 `:8080` | 改 `application.yml` 的 `server.port` 为 `80`，或装 IIS/Nginx 反代到 `127.0.0.1:8080` | 占用 80 需管理员权限 |
| 去掉 `:8443` | 把 `TlsConfig` 里的 `HTTPS_PORT` 改成 `443` | 443 同样需要管理员权限；改完 `http://pos.home.arpa/pos` 仍在 80 上，两者可并存 |
| 只保留一个入口 | 用 `http://pos.home.arpa/pos`（无摄像头）或 https 一个端口 | 安卓摄像头只有 https 能用，建议保留 https |

> 换端口后记得在防火墙放行新端口（`放行防火墙端口.bat` 里改成对应端口，或 `netsh advfirewall firewall add rule ...` 手工加）。

### 3.5 换域名后会丢设备身份（重要）

设备 ID 存在浏览器的 localStorage，**按域名隔离**。从 `192.168.x.x:8080` 换成 `pos.home.arpa` 后，收银台会重新弹“收银台初始化”。这时到后台 **设备管理 → 设备码**，生成 6 位码，在收银台点「绑定已有设备」输入即可，历史订单里记录的设备名不受影响。

## 四、HTTPS（8443）：手机摄像头扫码的前提

安卓 Chrome 的安全策略规定：只有 **https** 或 `localhost` 才允许页面调用摄像头。`http://192.168.x.x:8080` 打开时，`navigator.mediaDevices` 直接是 `undefined`，点扫码会提示改用 https。所以手机端要扫码，就必须走 8443。

### 4.1 两个地址的分工

| 地址 | 端口 | 谁用 | 摄像头 | 备注 |
|---|---|---|---|---|
| `http://主机IP:8080/pos` | 8080 | 主机上的浏览器、扫码枪、手输条码 | 安卓下不可用 | 不需要处理证书，最省事 |
| `https://主机IP:8443/pos` | 8443 | 手机、自助机 | 可用 | 首次要信任自签证书 |
| `https://localhost:8443/admin` | 8443 | 主机本机 | 可用 | 本机访问不受自签证书影响 |

两个端口同时监听，同一个数据库、同一份数据，互不影响。后台「设置」页会同时给出两个地址，二维码编的是 https 那个。

### 4.2 证书是自动的

- 启动时如果 `data/tls.p12` 不存在，会用 BouncyCastle 现场生成：RSA 2048、10 年有效、别名 `pos`、密码 `pos-local`，主题 `CN=POS Local Server`，SAN 里固定写入 `localhost`、`pos.home.arpa`、`127.0.0.1` 以及**当前所有局域网 IPv4**。
- 主机换 IP（换路由器/换网段）后，启动时发现 IP 不在证书 SAN 里，会**自动重签**并覆盖 `data/tls.p12`，不用手工删文件。
- 想手工重签：停服务 → 删除 `data/tls.p12` → 启动，即重新生成。

> 因为是自签证书，系统里没有公共 CA 背书，手机首次打开一定会提示「不安全 / 证书无效」。这属于正常现象：整套系统完全离线，不可能去申请公网证书。

### 4.3 手机上首次信任（安卓 Chrome）

1. 地址栏打开 `https://主机IP:8443/pos`。
2. 出现「您的连接不是私密连接 / 此网站的安全证书存在问题」页 → 点 **高级** → **继续前往 192.168.x.x（不安全）**。
3. 进入收银台后点右上「扫码」，浏览器会弹「允许使用摄像头？」→ **允许**。
4. 之后同一个浏览器、同一个地址不再提示，可以直接扫码。

要点：

- 一定要点「继续前往」，直接退回上一页的话页面根本不加载，摄像头也不会被请求。
- 如果在第 3 步点了「拒绝」，以后每次扫码都直接失败。修复：Chrome → 设置 → 网站设置 → 摄像头 → 找到该地址改成「允许」；或清除该站点数据后重进。
- 自助收银机如果是安卓一体机，同上；如果是 Windows 触摸屏，用 8080 即可，摄像头由扫码枪替代。

### 4.4 防火墙

`放行防火墙端口.bat`（右键 → 以管理员身份运行）会一次性放行 TCP **8080** 和 **8443**，并先删同名旧规则。手工等价命令：

```powershell
netsh advfirewall firewall add rule name="POS-Server 8443" dir=in action=allow protocol=TCP localport=8443 profile=any
```

首次启动 Java 时如果弹过「是否允许访问网络」，选「允许」也能放行（当前这台机器上已有 Java 程序的放行规则，协议为 Any）。

## 五、不折腾域名：二维码直接进

后台 **设置 → 手机 / 自助机访问** 现在会显示二维码，扫一下就是 `https://主机IP:8443/pos`（可调摄像头），并另给一条 `http://主机IP:8080/pos` 的备用地址；首页也有同一张码。

- 安卓：相机扫码 → 打开链接 → 浏览器菜单「添加到主屏幕」，以后点图标就进收银台。
- 打印出来贴在收银台，店员换手机也不用记地址。
- 二维码接口是 `GET /api/qr.png?text=...&size=...`，不联网也能生成（服务端用 ZXing 现画）。

代价：IP 变了二维码就失效——所以第二节的固定 IP 必做。

## 六、开机自启与崩溃自动重启

放在项目根目录的三个脚本：

| 文件 | 作用 |
|---|---|
| `start-service.bat` | 无窗口启动服务；进程退出后 5 秒自动重启（死循环守护） |
| `停止服务.bat` | 停掉占用 8080/8443 的 Java 进程（换 jar、改配置、重启前用） |
| `安装开机自启.bat` | **右键 → 以管理员身份运行**，创建计划任务 `POS-Server`（开机启动、SYSTEM 权限、最高优先级），并立即启动 |
| `卸载开机自启.bat` | 删除该计划任务 |

手工验证：

```powershell
schtasks /query /tn POS-Server
Get-Process java
```

日志：计划任务跑的是 `start-service.bat`，控制台输出不进日志文件。要看日志，可把脚本里的 `java -jar ...` 改成：

```bat
java -jar backend\target\pos.jar >> logs\pos.log 2>&1
```

（先在项目根建 `logs` 目录。）

## 七、新机部署清单

| 项 | 建议 |
|---|---|
| 系统 | Windows 11 64 位（专业版便于计划任务/远程） |
| 硬件 | i3/R3 级、8G 内存、128G 以上 SSD，集显足够 |
| 运行环境 | JDK 17（Temurin/Microsoft 均可）；不想装 JDK 可用 jlink 打自带运行时的绿色包 |
| 网络 | 网线接路由器 + DHCP 静态绑定固定 IP |
| 防火墙 | 右键 `放行防火墙端口.bat` → 以管理员运行，放行 TCP 8080 与 8443；首次启动 Java 弹窗选「允许」 |
| 电源 | 关闭睡眠/休眠；建议配 UPS，避免断电导致 SQLite 写入中断 |
| 外设 | USB HID 键盘楔入型扫码枪、58/80mm USB 小票打印机 |
| 迁移 | 整个目录拷走（`backend/target/pos.jar`、`web/`、`data/`、脚本）；或只拷 `data/pos.db` 到同路径 |

## 八、排错

| 现象 | 原因 / 处理 |
|---|---|
| 手机打不开 `pos.home.arpa` | 私人 DNS 没关；或手机 DNS1 没指向主机；或主机防火墙拦了 53 端口（AdGuard 要放行 TCP/UDP 53） |
| 域名能开但很慢 | 手机 DNS2 兜底在等超时，把 DNS1 设对、DNS2 留路由器即可 |
| 换了 Wi‑Fi 就失效 | 不同 Wi‑Fi 网段的 DNS 设置是独立的，需要在每个 Wi‑Fi 里各设一次 |
| 二维码扫出来是旧 IP | 主机 IP 变了，重做 DHCP 静态绑定，二维码会自动更新，重新截图即可（证书也会自动重签） |
| 手机点「扫码」没反应 / 弹窗提示要 https | 当前是 8080 的 http 地址，安卓禁止调摄像头；换 `https://主机IP:8443/pos` |
| https 提示「证书不受信任」 | 自签证书的正常现象，点「高级 → 继续前往」；之后可在手机「设置 → 安全 → 加密与凭据 → 安装证书」里信任它（可选） |
| https 能开但摄像头报 `Permission denied` | 之前误点过「拒绝」，到 Chrome 网站设置 → 摄像头 → 该地址改为「允许」，或清站点数据 |
| `https://主机IP:8443` 完全连不上 | 8443 没放行（跑 `放行防火墙端口.bat`）；或服务没起来（`Get-NetTCPConnection -State Listen` 看 8443）；或 IP 变了 |
| 服务启动报 `No SSLHostConfig element was found` | Tomcat 10 的坑：必须用 `SSLHostConfig` + `SSLHostConfigCertificate` 挂载，不能只给 Connector 设 `keystoreFile` 属性（当前代码已按正确方式实现） |
| 有画面但一直不识别 | 页面上「已取 N 帧」在涨说明解码循环正常：把条码横向铺满中间取景框、退到 15~25cm、别让条码贴膜反光；仍不行用下方手输或扫码枪。当前实现是自建取帧 + ZXing（`TRY_HARDER`，支持 EAN-13/8、UPC-A/E、Code128/39/93、ITF、QR），不走库自带的整帧解码 |
| 后台点「恢复备份」没生效 | 恢复是重启后替换，需重启服务（计划任务：`schtasks /end POS-Server` 再 `/run`） |
| 端口被占用 | `netstat -ano | findstr :8080` 查 PID，改 `application.yml` 的 `server.port` |
